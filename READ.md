# Expense Tracker

A console expense tracker built with Python and SQLite. It helps you record your spending and see where your money goes.

## Features

- Add expenses with amount, category, description and date
- View all expenses in a table
- Delete an expense by its ID
- Spending summary by category using SQL `GROUP BY`
- Input validation, so wrong input never crashes the program
- Data saved permanently in an SQLite database

## Menu

1. Add expense
2. View all expenses
3. Delete an expense
4. Summary by category
5. Quit

## How to run

1. Install Python 3
2. Download or clone this project
3. Run: `python expense_tracker.py`

## Technologies used

- Python 3
- SQLite (the built-in `sqlite3` module)
